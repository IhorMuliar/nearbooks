Attested on-chain

attested

NEAR mainnet state at the first block of each UTC day and at the first block 28 days earlier, read by the pinned worker inside OutLayer's Intel TDX enclave and stored by the contract. A row is verified only if, checked in this browser: the worker hash is one this repository vouches for, it is the contract's pin for that date, OutLayer's public attestation matches the snapshot's wasm, input and output hashes, and the attested transaction called this contract. The TDX quote and Intel signature are checked by contract/scripts/verify_attestation.py.

Contract and trust

on-chain

Re-pinning the worker or changing the OutLayer contract is timelocked. A re-pin only governs dates that start after it is applied, so a waiting proposal can never touch a date that has already begun. The owner can still upgrade the code through the account's full-access key (testnet prototype).
